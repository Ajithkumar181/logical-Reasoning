# 🔹 Mastering 2-Statement Data Sufficiency

These problems are **all about logic, not calculation**. The key is **sufficiency**, not the solution itself.

---

## 1️⃣ Step 1: Understand the Question

Always start by **understanding what’s being asked**.

* Identify **unknowns**.
* Figure out **what you need to answer**.

**Example:**

> What is the value of (x)?

Unknown → (x)

---

## 2️⃣ Step 2: Analyze Statement 1 Alone

Ask:

* Can I answer the question with only this info?
* If yes → Sufficient, if no → Not sufficient.

**Tip:** Do not combine statements yet.

---

## 3️⃣ Step 3: Analyze Statement 2 Alone

Same as above.

---

## 4️⃣ Step 4: Analyze Both Statements Together

* Sometimes neither alone works, but together they do.
* Check if the combination gives a **unique answer**.

---

## 5️⃣ Step 5: Use the Standard Answer Options

| Option | Meaning                                                   |
| ------ | --------------------------------------------------------- |
| A      | Statement 1 alone is sufficient                           |
| B      | Statement 2 alone is sufficient                           |
| C      | Both statements together are sufficient but neither alone |
| D      | Each statement alone is sufficient                        |
| E      | Even together, statements are not sufficient              |

---

# 🔹 Tricks to Make It Easy

1. **Unique solution rule** → Only 1 possible answer = sufficient
2. **Yes/No questions** → Must lead to definite yes/no
3. **Don’t assume** → Only use given info
4. **Combine statements carefully** → Check if ambiguity is removed
5. **Check multiple possibilities** → If more than one, NOT sufficient

# 🔹 Step 6: Practice Examples

### Example 1 – Number

**Question:** Find (x).

1. (x + 5 = 10)
2. (2x = 10)

* Statement 1 → (x = 5) ✅ Sufficient
* Statement 2 → (x = 5) ✅ Sufficient
* Both together → Redundant

**Answer:** D

**Question:** Age of Ravi?

1. Ravi’s brother is 10.
2. Ravi is older than his brother.

* Statement 1 → Not enough info
* Statement 2 → Not enough info
* Together → Still not enough

**Answer:** E

### Example 3 – Yes/No

**Question:** Is a triangle equilateral?

1. All angles equal ✅ Sufficient
2. All sides equal ✅ Sufficient

**Answer:** D

**Question:** What is the value of (x)?

1. (x + y = 10)
2. (y = 4)

* Statement 1 → Not sufficient
* Statement 2 → Not sufficient
* Together → (x + 4 = 10 → x = 6) ✅ Sufficient

**Answer:** C

* ✅ Do we need to combine?
* ✅ Even combined, is it unique?
