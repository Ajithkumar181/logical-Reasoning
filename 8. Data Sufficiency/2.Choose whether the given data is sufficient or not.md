## 🌟 PART 1: What Is Data Sufficiency?

**Definition:**
In *Data Sufficiency* questions, you are **not asked to solve completely**.
You just decide — **is the given data enough to find the answer?**

Each question gives:

* A **main question** (the actual thing to determine).
* **Two statements (I) and (II)** giving data.

You must decide whether the statements are **sufficient** to answer the question.

---

## 🌿 PART 2: The Five Standard Answer Options

| Option | Meaning                                                                                |
| :----: | :------------------------------------------------------------------------------------- |
|  **A** | Statement (I) alone is sufficient, but statement (II) alone is not sufficient.         |
|  **B** | Statement (II) alone is sufficient, but statement (I) alone is not sufficient.         |
|  **C** | Both statements (I) and (II) together are sufficient, but neither alone is sufficient. |
|  **D** | Each statement alone is sufficient.                                                    |
|  **E** | Even both statements together are not sufficient.                                      |

✅ **You never find the final answer — only check if it’s uniquely determinable.**

---

## 🧠 PART 3: Step-by-Step Method (Logical Thinking Flow)

1. **Understand the main question clearly.**
   Example: “What is the value of x?” or “Is x > 0?”
   → Identify whether it’s a **value-based** or **yes/no** type.

2. **Check Statement (I) alone.**

   * Can we find a **unique** answer?
   * If yes → (A) or (D).
   * If no → continue.

3. **Check Statement (II) alone.**

   * Same check.

4. **Now combine both (I) and (II)**

   * See if both together give a **unique** answer.
   * If yes → (C).
   * If still not enough → (E).

5. **Never assume extra facts** unless given (like integers, positives, etc.).

## 🧩 PART 5: Simple Examples with Explanation

---

### **Example 1**

**Question:** What is x?
(I) ( x + 2 = 5 )
(II) ( 2x = 6 )

✅ Step 1: From (I) → x = 3 → **unique** → sufficient.
✅ Step 2: From (II) → x = 3 → **unique** → sufficient.
✅ Each alone is sufficient.
**Answer: D**

---

### **Example 2**

**Question:** Is x > 0?
(I) ( x^2 = 9 )
(II) ( x = 3 )

From (I): x = ±3 → not sure of sign → **not sufficient**.
From (II): x = 3 → positive → **sufficient**.
**Answer: B**

---

### **Example 3**

**Question:** What is the value of y?
(I) ( 3y - 2 = 7 )
(II) ( y^2 = 9 )

(I) ⇒ y = 3 → unique → sufficient.
(II) ⇒ y = ±3 → not unique → not sufficient.
**Answer: A**

---

### **Example 4**

**Question:** Is n even?
(I) ( n^2 ) is even.
(II) n is divisible by 4.

(I) ⇒ If n² is even, n must be even → sufficient.
(II) ⇒ Divisible by 4 ⇒ even → sufficient.
**Answer: D**

---

### **Example 5**

**Question:** What is the area of the rectangle?
(I) Length = 5 cm.
(II) Perimeter = 16 cm.

(I) alone → width unknown → not enough.
(II) alone → both length and width unknown → not enough.
Together:
P = 16 ⇒ 2(L + W) = 16 ⇒ L + W = 8.
We know L = 5 ⇒ W = 3.
Area = 15.
Both together sufficient → **C**

## ⚡ PART 6: Quick Decision Table

| Situation                             | Conclusion         |
| :------------------------------------ | :----------------- |
| One equation, one unknown             | Sufficient         |
| Two equations, two unknowns           | Usually sufficient |
| One equation, two unknowns            | Not sufficient     |
| Multiple possible values remain       | Not sufficient     |
| Need both statements for unique value | (C)                |
| Each alone gives unique answer        | (D)                |

## 🧭 PART 7: Common Mistakes to Avoid

1. ❌ Don’t assume variables are integers unless stated.
2. ❌ Don’t try to find the actual number — just check if it’s **determinable**.
3. ❌ Don’t mix statements before checking each one separately.
4. ❌ Don’t ignore special values like 0, negative, fractions.
5. ✅ Always test **both positive and negative** if equations are squared.
